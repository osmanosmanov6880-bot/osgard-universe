# OSGARD Universe

A standalone responsive entry portal for OSGARD. This is not a clone of the existing OSGARD World game engine, API, account platform or infrastructure. Working external product routes open at https://osgard.world.

## Local development

Requires Node.js 22+. No third-party npm packages.

1. Run npm run dev
2. Open http://localhost:4173
3. Run npm run verify for security/static checks, tests and a static build.

## Five development waves

- Wave 1: accessible cinematic frontend, internationalization, safe zero-dependency HTTP server, source illustrations.
- Wave 2: verified catalog of 19 game destinations, search, genre filters, favorites and recent games.
- Wave 3: working Academy quizzes, browser-local progress and source-based Intelligence lab.
- Wave 4: Development case studies, actionable project brief, keyboard/mobile polish, translations.
- Wave 5: CI, repeatable static release, security checks, deployment guidance and rollback instructions.

## Integrity boundaries

- Original games, multiplayer sessions, user accounts, payments, streaming, and Godot/Unity builds are not hosted or simulated here.
- Saved lesson progress, favorites and project brief are browser-local, never a formal qualification or a synced user account.
- Evidence Lab contains educational examples with attributed sources, not a live AI answer.
- No production deployment is triggered by feature PRs. Do not replace osgard.world without explicit release approval and rollback.

## Assets

Existing OSGARD SVG scene images and selected game world illustrations are reused from the osgard-world repository. The planet illustration was drawn as a stylized new vector, not a NASA photograph.
